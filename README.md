# pure-admin-doc

Design system and visual style guidance for [pure-admin/vue-pure-admin](https://github.com/pure-admin/vue-pure-admin), formatted as `DESIGN.md`.

## Flip 7 score party

This repository also includes a playful static page inspired by the card-game aesthetic and the design tokens documented in `DESIGN.md`.

- Demo page: [`index.html`](index.html)
- GitHub Pages workflow: [`.github/workflows/pages.yml`](.github/workflows/pages.yml)
- Design reference: [`DESIGN.md`](DESIGN.md)

### GitHub Pages setup

1. Open the repository Settings → Pages.
2. Change Source to GitHub Actions.
3. Push to `main` or run the workflow once.

Once the deployment succeeds, the page will be available at:

https://ruzi-sudo.github.io/pure-admin-doc/

The page is static and stores score data only in the current browser.
